- 首次使用先确认账号角色和可见菜单。

## 快速入门

用最短路径完成登录、数据浏览、空间查询和结果处理，适合普通用户和科研用户首次上手。

### 首次使用流程

1. 登录平台：打开系统地址，输入账号和密码。若平台开放注册，可按页面入口创建普通账号。
2. 进入地理数据：通过顶部导航进入地理工作台，在左侧数据面板检索资源并查看元数据。
3. 加载图层：选择可渲染或可查询资源，点击快速加载或查询并加载，资源会进入图层树。
4. 查看结果：在右侧信息面板查看资源、图层、地图视角和选中要素属性，按权限进行导出。

### 首次使用检查

- 确认当前账号角色和可访问菜单。
- 确认需要查看的数据资源是否在可见范围内。
- 保存常用工程或专题，方便后续恢复工作场景。

## 地图面板与屏幕适配

左右侧栏边缘的小箭头可分别收起数据栏、分析栏；收起后仍可展开，缩略图保持显示。

### 展示操作

- 顶部地理工作台按基础地理、栖息地、分布与专题分类进入对应资源。种质采样位置展示空间位置，基因序列和实验值进入数据分析。
- 地图上方按钮可分别收起或展开左右侧栏；收起右侧分析栏时保留地图缩略图。
- 用侧栏边缘箭头收起左右面板，再收起底部空间检索，即可专注展示大球与缩略图；再次展开后图层和地图视角保留。
- 底部空间检索收起后显示居中操作条，展开时根据侧栏宽度调整范围。
- 小屏幕切换地图、数据和分析面板；表格和基因组选项在各自容器内滚动，图表随容器宽度调整。

## 地理数据工作台

介绍地图主视图、左侧数据面板、右侧信息面板和图层树的协作方式。

### 工作台组成

- 地图主视图：承载地图浏览、要素点击、范围绘制和图层渲染。
- 左侧数据面板：支持关键字、业务类型、数据类型、来源和日期范围筛选。
- 图层页签：管理已加载图层和图层组，支持显示隐藏、定位、数据表、符号化、导出和移除。
- 右侧信息面板：展示选中资源、图层、要素和地图视角信息。

### 栅格渲染边界

栅格文件的符号化和瓦片生成由后端完成，前端只加载后端输出的影像或瓦片服务。

## 空间查询工作台

说明如何定义空间范围、选择查询对象、执行查询并处理空间查询结果。

### 查询流程

1. 定义查询范围：使用矩形、圆形、椭圆、多边形、当前视图、图层范围或导入 GeoJSON 定义空间区域。
2. 选择查询对象：从资源目录选择可查询矢量资源，或从已加载矢量图层中选择当前工作对象。
3. 执行查询：点击执行查询后查看命中数量、返回数量、耗时、结果边界和数据质量警告。
4. 处理结果：将结果加载为图层、定位到结果范围、打开属性表、导出数据或清空当前查询。

### 无结果排查

- 确认查询对象是可查询矢量资源，栅格图层不能作为空间查询对象。
- 确认绘制范围与目标资源的空间范围存在交集。
- 确认资源处于启用状态，且当前账号有访问和查询权限。
- 若结果被截断，可缩小范围或叠加属性条件后再次查询。

## 属性查询与图层管理

说明属性条件筛选、结果加载、图层排序、符号化和导出等常用工作流。

### 属性查询

1. 选择可查询资源：在数据面板中选择矢量资源并查看字段列表。
2. 添加字段条件：选择字段、运算符和值，支持包含、等于、不等于、大于、小于和介于等条件。
3. 查询并加载：执行查询后将结果加入图层树，并在属性表中继续查看或导出。

### 图层常用操作

- 保存为工程：保存当前图层组合、视角和状态。
- 保存为专题：围绕特定业务场景共享图层组合和展示状态。
- 符号化：调整矢量或栅格图层样式；栅格重新符号化会触发后端渲染。
- 移除图层：只从当前工作台移除，不删除原始数据资源。

## 非地理数据分析

按科研数据类型选择页面，上半部切换类型，下半部筛选并选择资源。图表、表格和文字概述联动更新。

### 页面与用途

| 页面 | 展示内容与用途 |
| --- | --- |
| 生态观测 | 按个体、种群、群落与物种功能性状筛选资源；展示科属组成、样方物种矩阵、性状与多样性分布、箱线图、生态指标相关矩阵和散点。保留原始字段，与地理工作台侧重空间分布形成互补。 |
| 种质数据 | 材料、区域和性别组成，来源-性别-材料流向与核心种质数量；核心子集不可与母集相加。 |
| 分子数据 | 按测定指标和单位查看测定值、批次分布、箱线图与质检统计；不同指标先筛选再比较。 |
| 基因组概览 | 染色体环形多轨图、线性长度、GC和基因密度，了解参考组装结构。 |
| 基因结构 | 按基因编号或染色体区间检索，查看外显子、CDS与方向，读取和下载配套序列。 |
| 组装比较 | 两套组装的长度、基因数、蛋白数、N50和GC比较；同名染色体不代表同源比对。 |
| 序列统计 | 基因组、基因区段、蛋白、转录本与编码序列的长度、组成和分布。 |

### 常用操作

1. 选择资源：先选择数据类型，再在资源区按名称、编号或来源搜索。基因数据提供基因组概览、基因结构、组装比较与序列统计。
2. 调整分析：分组依据选择生活型、物种等类别，统计指标选择株高、含水率等数值；二者分别控制分类和测量维度。再按关键词或条件限定范围，统计覆盖全部筛选记录。保存后可从页首恢复。
3. 查看和下载：先读结果概述，再结合图表查看分布与关系。下载结果提供数据表和文字摘要，图表可单独下载SVG。点击“生成报告”可预览全部配套图表，勾选图表、调整顺序并编辑标题、图注和文字；保存为高清PDF草稿，提交审核后由成果管理员审核发布，随后进入成果展示。草稿可重复打开修改，待审核和已发布报告冻结编辑，退回后可按意见修订。

### 科研解释

RNA FASTA是转录本序列，不是表达量。GFF主要描述基因结构，不等于GO/KEGG功能注释。FG为雌株，MG为雄株；两套组装坐标和基因编号各自独立。

## 分析数据的准备与导入

统一从导入数据资源进入，按选择数据、核查校验、确认入库三步完成。字段规范和数据资源模板集中在本帮助页。

### 三步导入

1. 选择数据：进入数据资源 → 数据导入 → 导入数据资源 → 非地理数据。表格直接拖拽或选择文件；基因组按角色选择同一版本的序列与结构注释。FG、MG分别导入，不混用配套文件。
2. 核查校验：填写名称、选择数据类型和资料来源后开始校验。表格核查记录编号、必填信息、数值及单位，展示记录数与前八行；Excel可填写工作表名称，留空读取第一张。基因组解析序列、结构、坐标与关联编号。此步不登记资源，修改文件或参数后需重新校验。
3. 确认入库：校验通过后进入确认页。核对名称、类型、文件和记录数，点击确认入库；服务端重新检查文件，通过后才登记资源。失败可返回修改重试，成功后可打开分析或继续导入。

### 支持格式与文件角色

| 资料 | 文件与要求 |
| --- | --- |
| 生态观测、种质、分子及序列统计表 | CSV、TSV、分隔文本TXT、XLS、XLSX，以及CSV.gz、TSV.gz、TXT.gz。文本支持UTF-8或GB18030编码；TXT以逗号、制表符、分号或竖线分隔。一个资源对应一个工作表，保留附加字段。 |
| 基因组DNA序列 · 必选 | FASTA、FA、FNA，可gzip压缩；以>序列编号开头。 |
| 结构注释 · 必选 | 同一组装的GFF或GFF3，可gzip压缩；序列编号、坐标、ID和Parent需与配套序列一致。 |
| 蛋白、转录本和编码序列 · 可选 | 蛋白FAA/FASTA、RNA FASTA、CDS FASTA及其gzip。选择后参与配套关系检查；没有对应文件可留空。 |
| 基因CSV的用途 | 序列统计CSV可作为表格上传。基因组配套清单CSV仅用于整理文件，不作为序列上传；导入基因组时仍须逐项选择原生FASTA和GFF文件。 |
| 暂不接入的原始文件 | FASTQ测序读段、BAM比对文件等先通过专业生物信息流程处理；当前分析不提供基因表达、功能注释和遗传变异页面。 |

### 填写规则与缺测处理

- 帮助页右侧下载数据资源模板。每种资料提供空白CSV和带示例CSV；保留表头，从第二行填写，每列一个变量、每行一条记录。示例仅演示填写方式，导入示例时选择模拟资料。甲方原个体、种群、群落和种质表的已适配中文表头可直接使用。
- 保留编号的前导零。个体保留采集号和物种，种群保留样方编号和物种，群落保留样方编号；种质至少有样品编号。生态记录编号未提供时按原始行号生成，不代表新增生物个体。
- 功能性状保留物种，记录编号可自动生成，样方可空。分子保留测定编号、样品编号、指标及单位；实验编号、批次、重复、时间和测定值允许缺测，同一资源使用一种单位。每条测定编号唯一，指标比较先筛选同一指标。
- 空白、NA、N/A表示缺测，不能填零替代。零值保留，温度可为负数。GC比例及叶片含水率采用0–1；核酸长度用bp，蛋白长度用aa，两种长度不互换。分子value为非负测定值，有符号的其他变量保留附加字段并注明含义。
- 经纬度、采集地点及多数测量字段可空。未知性别归为未确认并保留原文，核心种质归属未提供时留空，不自动判为否。非标准坐标保留原文，不参与地图定位；数值坐标仍检查合理范围。
- 表格上传限16MiB、20万行，文本展开限64MiB。基因配套合计限512MiB，展开限4GiB；完整基因组解析需要时间，保持页面打开。更大基因组使用服务器管理命令接入。

## 分析报告与成果发布

以一份原始资料为单位生成可编辑的图文PDF报告，草稿经审核发布后进入成果展示。

### 报告流程

1. 生成与编辑：在分析页面选择一份资源，调整筛选后点击生成报告。报告记录数据来源及当前分析范围；图表支持勾选、排序、修改标题和图注，分析段落可增删修改。
2. 预览与保存：点击更新预览检查分页、图表和文字；保存PDF草稿后可下载，也可在成果管理中继续编辑同一份草稿。
3. 审核与发布：提交审核后报告冻结编辑。具有成果发布权限的管理员可填写意见退回，或设置访问角色后审核发布。只有已发布报告进入成果展示，支持PDF预览及下载。
4. 导入已有报告：数据导入 → 导入成果 → 非地理分析报告（PDF），选择文件、名称和分类，导入为草稿后提交审核。外部PDF保持原文件，不提供图文内容再编辑。

## 数据与成果导入

说明数据资源导入与成果文件直接发布两条流程，以及导入前的数据准备和权限要求。

### 支持类型

| 类型 | 格式 | 处理方式 |
| --- | --- | --- |
| 表格 | CSV、XLS、XLSX | 导入为空间点表或普通属性表。 |
| 栅格 | TIF、TIFF、IMG、VRT、DAT、BSQ、BIL、BIP | 预检后上传，后台预处理为可切片渲染的数据集。 |
| 矢量 | GeoJSON、JSON、GPKG、KML、KMZ、SHP、ZIP | 执行图层、编码、坐标系和几何质量预检后入库。 |
| 成果 | PNG、JPG、PDF、CSV、XLSX | 登记元数据、选择访问角色并直接发布，不创建导入草稿。 |

### 通用流程

1. 选择文件：拖拽或选择文件，系统会根据扩展名进入对应导入流程。
2. 填写资源信息：补充名称、来源、提供单位、业务类型、数据日期、访问范围和说明。
3. 确认结构与质量：表格确认字段和坐标，栅格确认波段和规则，矢量确认坐标系和几何质量。
4. 提交导入：完成校验、入库或预处理后，到存量数据中继续维护默认样式和权限。

## 数据准备规范

说明导入前应整理的数据名称、字段、坐标、元数据和敏感信息，减少后续返工。

### 命名与字段

- 推荐使用“区域 + 对象 + 指标/主题 + 时间/批次”的命名方式。
- 一列只表达一种含义，数值字段不要混入单位、备注或中文说明。
- 日期字段统一为 YYYY-MM-DD，样地、样本、个体和监测点编号应长期稳定。

### 导入前检查

- 经纬度是否为十进制度，坐标精度是否一致。
- 来源单位、采集日期、调查人员和质量说明是否完整。
- 敏感样地、内部资料和未公开成果是否设置了合适的访问范围。

帮助数据管理员理解数据资源列表、启停状态、访问角色、默认可视化和导出能力。

### 维护事项

- 按关键字、数据类型、业务分类、来源和启用状态筛选存量资源。
- 创建自定义组别，拖拽资源到组别中；删除组别不会删除数据。
- 维护资源名称、摘要、来源、提供单位、数据日期、访问角色和启停状态。
- 配置默认显示样式，便于用户快速加载统一样式。
- 导出 CSV 或 XLSX 清单，用于数据盘点和项目验收材料。

### 删除确认

删除资源会移除资源登记和关联图层；用户导入的表或矢量图层会同步清理。删除前应确认备份与业务影响。

## 工程、专题制图与成果管理

说明工程、专题图成果和导入成果的区别，以及在数据管理中心维护发布范围和基本操作的方式。

### 概念区别

- 工程：更偏个人或团队工作状态，保存图层组合、地图视角、符号化和分析上下文。
- 专题制图：以工程为来源配置纸张、地图框、标题、图例、比例尺、指北针和区位图，并生成正式成果版本。
- 成果管理：统一管理专题图与导入/分析成果，支持预览、下载、发布范围、下架、重新发布和删除。
- 访问角色：专题图和导入成果均需配置可见用户组，功能权限决定用户能否查看、下载或管理。

### 发布前检查

- 图层名称、顺序和样式是否清晰。
- 专题说明是否写明数据来源、时间范围和适用场景。
- 访问角色是否与数据授权范围一致。

## 后台运行概览

介绍后台管理入口中的运行概览、个人设置、系统设置和管理员常用维护动作。

### 后台模块

- 运行概览：查看资源数量、导入任务、用户状态、日志摘要和系统健康信息。
- 个人设置：维护个人资料、安全信息和登录状态。
- 系统设置：配置注册开关、地图中心、上传上限、查询上限、底图和运行参数。
- 数据备份：发起或查看备份任务，确认业务数据和研究数据的保护状态。

### 权限边界

前端按钮是否显示只用于提升易用性，敏感操作仍必须由后端权限校验兜底。

## 权限与日志

说明用户、角色、权限组、操作日志和系统日志的管理重点。

### 认证授权内容

| 对象 | 管理内容 |
| --- | --- |
| 用户 | 新建、启停、重置密码、调整角色、设置单独权限、查看日志。 |
| 科研用户申请 | 查看待审核申请，通过或拒绝申请。 |
| 角色 | 查看内置角色基线，新建自定义角色，维护功能权限。 |
| 日志范围 | 配置指定用户可查看哪些角色的操作日志。 |

### 管理重点

- 用户管理：创建账号、调整角色、启用或禁用用户，并查看用户基础信息。
- 用户组管理：通过角色和权限组控制菜单、数据资源、导出、导入和后台功能。
- 操作日志：追踪登录、导入、导出、权限调整、配置修改和删除等关键动作。
- 系统日志：用于排查运行异常、导入失败、后台任务错误和接口问题。

### 审计建议

- 定期检查管理员账号和高权限用户列表。
- 排查频繁失败登录、异常导出和集中删除操作。
- 重要配置变更前后保留日志截图或导出记录。

## 备份与数据安全

说明平台数据生命周期、备份策略和安全使用建议。

### 数据生命周期

1. 准备：整理原始文件、字段说明、坐标系、来源单位、时间范围和质量说明。
2. 导入：通过数据导入页面完成校验、入库、栅格预处理和访问范围配置。
3. 维护：在存量数据中更新元数据、启停状态、默认可视化和授权范围。
4. 归档：阶段性导出数据清单，结合后台备份任务保存业务数据和研究数据。

### 安全建议

- 不要把业务数据根目录或研究数据根目录硬编码到前端代码或公开文档中。
- 敏感数据仅授予必要角色可见，导出权限应独立控制。
- 删除、权限调整和系统设置变更前确认备份状态。

## 常见问题

### 导入数据前最容易忽略什么？

最容易忽略字段含义、坐标系、采集日期和访问范围。建议在导入前先补齐字段说明、来源单位、数据日期和敏感信息判断。

### 空间查询没有结果时应如何排查？

先确认查询对象是可查询矢量资源，再检查绘制范围是否与资源空间范围相交、资源是否启用、账号是否有权限，以及左侧属性条件是否过严。

### 同名数据继续导入会覆盖旧数据吗？

不会。系统会创建新的数据记录。为便于后续管理，建议在名称中加入区域、日期、批次或版本号。

### 管理员如何为用户分配数据查看权限？

在后台用户与用户组管理中维护角色，再在数据资源、工程或专题中配置访问角色。前端可见性不是最终安全边界，后端仍会校验权限。

### 帮助文档 PDF 可以离线使用吗？

可以。页面提供 PDF 下载按钮，适用于培训、验收附件和离线阅读。平台功能继续迭代后，应同步更新 PDF 文件。
