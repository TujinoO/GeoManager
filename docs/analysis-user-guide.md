# 数据分析：页面介绍与操作说明

更新：2026-10-30。

可以这样介绍：“地理工作台回答数据在哪里，数据分析回答数据有什么特点、不同指标有什么关系。平台按生态观测、种质、分子和基因四类展示资料，并能把一份资料的图表与分析整理成报告，审核后作为成果发布。”

| 页面 | 对应资料 | 主要展示内容与用途 |
| --- | --- | --- |
| 生态观测 | 甲方个体、种群、群落模板及功能性状表 | 分类组成、数值分布、分组箱线图、双指标关系、生态指标相关矩阵；比较不同物种、样方和环境指标。保留原始字段，坐标不是必填分析条件 |
| 种质数据 | 种质名录、采集和保存记录 | 样品来源、性别、材料组成、核心种质和分类流向；关注材料构成与保存利用，坐标只在明细保留 |
| 分子数据 | 分子标记、相对测定等实验长表 | 测定值分布、批次比较、质检统计及明细；按标记和单位分别比较，可用处理、时间、重复等字段筛选 |
| 基因数据 | FG/MG参考基因组及配套文件 | 环形/线性基因组图谱、长度/GC/基因密度、基因结构和序列、组装规模比较；另保留表达热图、功能注释和变异分析入口，需相应资料才显示结果 |

左侧上半区选类型，下半区选资源；生态观测可进一步筛选个体、种群、群落、性状。表格资源包含分析总览、组成与分类、分布与相关、数据明细、数据检查。分组依据选择物种、样方分组等类别，统计指标选择高度、多样性等数值，两者作用不同。

## 资料上传

顶部“数据导入 → 导入数据资源 → 非地理数据”。选择资料类型，下载模板或直接使用甲方已适配的原表，先“仅校验”，再“校验并导入”。分析页面不再单独设置导入入口。

| 文件 | 上传方法 |
| --- | --- |
| 个体、种群、群落、性状、种质、分子表 | CSV、TSV/TXT、XLS、XLSX；一份资源一张数据表，Excel当前读取第一张，其他工作表请单独另存。原始字段及额外列保留，界面显示专业中文 |
| FG/MG原生基因数据 | 在同一非地理入口选择基因配套文件；一套组装上传一组文件。基因组FASTA/FNA和GFF/GFF3必选，蛋白FAA、RNA、CDS可选；支持gzip压缩。FG和MG分别上传，文件中的序列/基因编号必须相互匹配 |
| 表达、功能、序列统计、变异表 | 选择对应基因数据表模板上传；RNA序列不能代替表达矩阵。样本VCF/VCF.gz需指定参考组装和GT，当前支持双等位单碱基及短插入缺失 |

表格单次16MiB、20万行，文本解压64MiB；原生基因文件合计512MiB、解压读取4GiB。超限会提示，不以部分记录冒充全量。

缺测留空或NA，不补零；性别原文无法确认时保留并提示；未提供物种、材料和核心种质归属时不推断。坐标为度分秒等格式时可保留原文，但不参与空间定位。

## 生成报告与发布成果

1. 选择一份资源，确定筛选范围、分组和指标，点击“生成报告”。
2. 弹窗自动准备图表和文字；勾选需要的图表、调整顺序，修改标题、图注和分析段落，点击“更新预览”。表格报告提供该资源当前筛选下的适用图表；基因报告收录当前分析页图形。
3. 保存PDF草稿，可下载核对，也可从成果管理返回原草稿继续修改。报告为A4高清页面合成PDF，单图仍可下载SVG。
4. 提交审核后冻结编辑；审核者可退回并填写意见，作者修改后重新提交。审核通过时选择可访问角色并发布，才会进入成果展示。
5. 已有外部PDF在“数据导入 → 导入成果 → 非地理分析报告”上传，形成草稿，再提交审核。外部PDF支持预览与发布，不转换成可编辑图表。

“下载结果”提供筛选后的CSV和文字摘要；每张图右上角提供SVG。成果展示支持PDF预览、下载，并能返回关联原始资源，访问仍由权限控制。

## 可直接使用的分子示例

文件在甲方原有“数据模板”目录，只有三份：

- 分子数据模板.csv：标准空表。
- 分子数据示例_模拟.csv：72条相对测定记录，3种处理、4个时间、每组6个生物重复。
- 分子数据上传说明.txt：简短上传步骤与字段说明。

示例是明确标注的模拟测定，不对应未经验证的真实基因。上传时选择“分子数据”和“模拟资料”，可展示分组、分布、筛选及报告流程。

## 解释图表时

统计基于全部筛选记录，不只当前分页；缺失不补零。箱线图表示最小值、Q1、中位数、Q3、最大值。相关性不代表因果；功能多重归属和核心种质子集不能重复累加。组装规模比较不等于序列比对、差异表达或雌雄群体差异检验。图形为保证可读性设显示上限，明细和CSV保留全部筛选记录。
