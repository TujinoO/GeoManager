# 数据分析模块：页面与演示说明

更新：2026-10-30。入口：顶部“数据分析”。左栏上半部选择数据类型，下半部检索、筛选和选择资源；右侧展示图表、结果概述和明细。沿用平台深色顶部、青绿磨砂侧栏和浅色内容区。

## 向其他人介绍

“平台把地图之外的资料分为生态观测、样品与种质、分子实验、基因组与组学四类。每类资料都能从统一资源目录中选择，联动查看统计图、记录和简要分析；基因数据还可以从染色体一直查看到基因结构与序列。数据统一导入，图表和分析结果统一下载。”

| 页面 | 数据是什么 | 展示与功能 | 介绍重点 |
| --- | --- | --- | --- |
| 生态观测 | 个体、群落、种群调查与功能性状 | 样方×物种观测矩阵、性状五数分布、分类组成、直方图、双指标散点与相关 | 看群落组成和性状差异；矩阵表示观测记录数，不直接代表丰度 |
| 样品与种质 | 样品名录、采集来源、性别、材料与核心种质 | 来源→性别→材料流向图、种质组成、核心子集、筛选明细 | 看样品从哪里来、有哪些材料；核心种质是登记样品子集 |
| 分子实验 | 生化测定、分子标记及实验结果 | 指标分布、分批次五数概括、质检记录与明细 | 当前可展示叶片全氮和全磷；切换指标前先核对单位和实验对象 |
| 基因组概览 | 参考组装的DNA、注释和配套序列 | 环形多轨道/线性染色体、长度、GC和基因密度，点击联动染色体窗口 | 先认识基因组整体，再定位具体染色体 |
| 基因结构 | GFF3注释中的基因、转录本、外显子与CDS | 编号检索、区间筛选、结构轨道、配套DNA/RNA/CDS/蛋白查看与FASTA下载 | 从基因编号追踪结构和序列 |
| 组装比较 | FG与MG等参考组装 | 总长度、基因数及染色体长度并排对照 | 比较参考组装规模；这里不等同于序列比对或雌雄群体差异检验 |
| 序列统计 | 基因组条目、基因区段、转录本、CDS、蛋白长度表 | 序列类别、长度与GC分布、关联基因及明细 | 核酸用bp，蛋白用aa；基因区段含内含子，不等同于CDS |
| 基因表达 | 基因×样本的表达长表 | log表达/行Z分数热图、样本相关矩阵、基因分组气泡 | 看相对表达模式；RNA序列文件本身不是表达矩阵 |
| 功能注释 | 基因与功能条目的对应关系 | 共注释关系图、功能条目覆盖矩形图、分类及明细 | 看哪些基因共享注释；关系边不表示蛋白互作或富集显著性 |
| 遗传变异 | 参考组装上的位点与样本基因型 | 染色体位置分布、替换类型、质量分布与基因型明细 | 区分样本位点记录与独立位点，避免重复统计 |

每个表格资源保留“分析总览、组成与分类、分布与相关、数据明细、数据检查”标签。专题入口和分析标签使用明确的按钮分组，青绿色选中态指示当前位置。专业图形未因分类调整而减少。当前没有真实表达矩阵、功能注释长表或变异文件，相关页面保留导入和分析能力，待接入相应数据后显示图形。

工具栏的“分组依据”用于选择生活型、物种等类别，“统计指标”用于选择株高、含水率等数值。前者决定分类图类别，后者决定数值分布和相关图的测量指标，选择后分类对照图显示指标均值。记录编号、测定编号、调查日期和数值字段不混入常用分类选项；组合筛选和明细仍保留全部字段。

## 数据导入与下载

统一入口：“数据资源 → 数据管理 → 数据导入”，或顶部“数据导入”，选择“非地理与基因数据”。分析页不再单独设置导入模块。

| 数据 | 支持文件 | 整理方式 |
| --- | --- | --- |
| 性状、样品、实验、序列统计、表达、功能、变异长表 | CSV、XLSX、TSV、TXT | 使用对应空模板；XLSX首张工作表为数据，字段说明放在第二张 |
| 参考基因组 | FASTA/FNA及gzip，配套GFF/GFF3及gzip | 基因组与GFF必选；FAA蛋白、RNA、CDS为可选角色；按原始编号关联 |
| 样本变异 | VCF、VCF.gz | 指定参考组装；必须有样本GT；当前支持双等位单碱基/短插入缺失，多等位和结构变异需先规范拆分 |

表格单次16MiB、最多20万行，文本解压上限64MiB；原生基因组累计上传512MiB、解压读入4GiB。导入前先校验，提示缺列、编号重复、错误数值和不支持的格式；不会默默截取部分文件作为全量。

“下载结果”统一提供数据表CSV、含当前可见图表的分析报告、文字摘要。报告为可离线打开的HTML，可通过浏览器“打印→另存为PDF”。每张图另有SVG矢量下载，基因序列可下载FASTA。保存的分析从页首“已保存的分析”重新打开。

## 展示数据包

独立保存18份来源明确的数据表：FG/MG各5类序列统计共10份、群落性状1份、叶片氮磷测定2份、样品种质5份。另外提供7类CSV与Excel空模板，以及FG/MG chr01前100kb的两套原生文件。18份表已通过正式导入接口接入本地平台，FG局部文件另经网页实际上传成功。

真实来源包括用户历史调查/种质工作簿和GWH公开FG/MG参考组装。原文件保留，转换说明在数据包的“导入说明.md”。缺失留空，未补造日期、批次或质检结果；619份核心种质与已有样品重复归属，跨资源不能直接相加。

## 3—5分钟演示顺序

1. 生态观测选“群落物种功能性状”，看2411条观测的矩阵和分布；组合筛选后观察统计、明细与下载同步变化。
2. 样品与种质选“胡杨群体种质资源_03”，看2022份样品的流向和组成，再切核心种质子集说明619份的子集关系。
3. 分子实验选择“叶片全氮测定”或“叶片全磷测定”，介绍测定值与g/kg单位；原表未给出的批次、质检留空。
4. 基因组概览选FG或MG，展示环形/线性切换和染色体联动，再在基因结构中检索GWHPBHNV000001或GWHPBHOO006919，查看结构与蛋白。
5. 组装比较看FG/MG；序列统计选FG蛋白质，说明长度分布和核酸/蛋白单位。
6. 下载含图分析报告，最后打开统一导入页，展示独立数据包、空模板和配套基因文件。

## 图表含义与边界

- 图表、统计、分页和CSV共用筛选；统计基于全部筛选记录，零值保留，缺失不补零。
- 五数箱体为Q1–Q3、中线为中位数，须端为实际最小/最大值；悬停显示有效n，不是1.5IQR须线。
- 表达色标log2(value+1)，行Z分数在当前显示样本内计算；常数行和缺失留空。相关矩阵另列有效配对数；气泡面积表示严格正值比例。
- 功能条目允许多重归属，节点与矩形按去重基因数；条目合计不是基因总数。
- 变异位置图终点为最大导入坐标，不自动代表染色体长度。同一位点不同样本分别记录。
- 图形维度有明确上限：分类30组、五数18组、生态矩阵24×24、表达40基因×24样本、气泡24×12、相关24样本、功能20条目、变异24条染色体×30箱。明细与数据导出保留全部筛选记录。
- 基因坐标采用1-based closed；chr别名来自原文件头，不按FASTA顺序编造。组装比较不推导共线性、差异表达、富集或GWAS结论。

## 地理工作台联动

顶部地理菜单按基础地理、生境环境、胡杨分布与专题资料分类；非地理资料进入上述四类分析。地理左右栏通过各自边缘的小箭头独立收起，收起后在屏幕边缘展开；缩略图继续显示。再收起底部空间检索即可专注地图。底部检索随侧栏状态及可用宽高调整，平板与手机保留内部滚动。
