# 数据分析实施说明

更新：2026-10-30。本任务依次完成合同、后端、前端和验证交接；合同及开发说明已同步。保留原工作区未提交内容。

## 信息结构

数据类型根为生态观测、种质数据、分子数据、基因数据；这是分析页面的四类组织方式，映射平台既有权威分类的叶节点，不另建业务分类树。生态观测包含个体、种群、群落和功能性状。基因子页保留概览、结构、组装比较、序列、表达、功能、变异。

左侧仅类型导航和资源检索两区。保存条件移至页首；导入、空模板、格式校验归统一数据管理入口。青绿磨砂侧栏与平台浅色内容保持一致；窄屏折叠导航，图表自动调整尺寸，宽表/基因轨道内部滚动。

## 数据与服务

保留现有DataResource、GenomeDataset、GenomeAssembly、GenomeAnnotation边界；GenomeIndex保存专业索引状态/文件清单，AnalysisView按用户隔离。业务与科研目录由TOML指定，程序、元数据、原始文件和索引分开。资源发布前须成功建立索引。

专业表支持individual/population/community/traits/samples/molecular/sequence/expression/function/variants。读取CSV/XLS/XLSX/TSV/TXT及样本VCF；原生基因组按5种文件角色关联。后台统一过滤、全量统计、分页和CSV导出。中文原始字段和群落英文别名在导入时明确映射，额外字段保留；专业中文用于前端展示。

统一入口只分“导入数据资源”和“导入成果”。导入数据资源内选择地理或非地理；非地理表格、配套基因文件在此完成模板下载、检查和上传。首页继续用权威业务分类索引，同时标明表格、文本、基因等物理类型。

报告以单个原始资源及当前筛选为单位。表格报告汇集分类、分布、组成、相关及适用的专业图表，不局限于当前标签；原生基因报告汇集当前分析页的图形。弹窗可预览、选择与排序图表、修改标题/图注、增删分析文字。保存为A4、240dpi的PDF草稿，沿用ResultArtifact；提交审核后冻结编辑，退回带修改意见，审核发布后进入成果展示并关联原始资源。外部非地理PDF从导入成果进入相同审核流程。PDF由高清页面合成，单图仍可另存SVG；PDF本身不是可检索的矢量文字报告。

甲方个体、种群、群落、种质模板分别以23、156、516、663条记录实测导入；完整功能性状2411条、33字段也已导入。原始文件未改动。分子测定暂无对应真实来源，另交付72条明确标注模拟的相对测定数据。FG/MG完整参考组装及既有图形保留。真实表达、功能、变异尚缺，保留对应能力，不填造研究结果。

## 科学表达

缺失不补零，NA等按缺测处理，允许原始气候负温度；不补造种质物种、材料或核心归属。无法确认的性别保留原文并归未确认，非十进制坐标保留并提示不用于定位。数值单位分开；核酸bp、蛋白aa，基因跨度不冒充CDS。GC以ACGT为分母。基因坐标对外1-based closed，内部0-based half-open。编号跨文件精确关联，不按顺序。组装比较不能替代序列比对；多重功能归属不能相加为独立基因总数，核心种质不与登记样品重复相加。

## 界面与同步优化

地图左右栏通过边缘箭头收起及展开，缩略图保留，中央不设置面板按钮组；空间检索按侧栏状态及可用屏幕空间布局。顶部菜单适应宽度，必要时内部横向滚动。专题和分析标签强化按钮选中态，分组依据与统计指标有独立标签及选项。环图底注位于独立留白区，随SVG导出。在线帮助、离线PDF及页面介绍同步更新。
