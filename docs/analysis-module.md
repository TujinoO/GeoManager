# 数据分析实施说明

更新：2026-10-30。本任务依次完成合同、后端、前端和验证交接；合同及开发说明已同步。保留原工作区未提交内容。

## 信息结构

数据类型根为生态观测、样品与种质、分子实验、基因组与组学；不将“导入”和“数据检查”混为数据类型。基因子页含概览、结构、组装比较、序列、表达、功能、变异。顶栏下拉与资源目录跳转遵循同一分类。

左侧仅类型导航和资源检索两区。保存条件移至页首；导入、空模板、格式校验归统一数据管理入口。青绿磨砂侧栏与平台浅色内容保持一致；窄屏折叠导航，图表自动调整尺寸，宽表/基因轨道内部滚动。

## 数据与服务

保留现有DataResource、GenomeDataset、GenomeAssembly、GenomeAnnotation边界；GenomeIndex保存专业索引状态/文件清单，AnalysisView按用户隔离。业务与科研目录由TOML指定，程序、元数据、原始文件和索引分开。资源发布前须成功建立索引。

专业表支持traits/samples/molecular/sequence/expression/function/variants。读取CSV/XLSX/TSV/TXT及样本VCF；原生基因组按5种文件角色关联。后台统一过滤、全量统计、分页和CSV导出；前端提供中文字段、图表、文字解释及含图报告。报告仅嵌入当前可见图表，按当前筛选生成，保留来源并转义资源文本。

来源明确的18份独立表已走正式导入流程。FG/MG完整参考组装保留；原生局部文件用于快速演示上传。旧合成数据仅停用，未删除、未重标真实。真实表达、功能、变异尚缺，页面保留对应能力，不填造结果。

## 科学表达

缺失不补零，数值单位分开；核酸bp、蛋白aa，基因跨度不冒充CDS。GC以ACGT为分母。基因坐标对外1-based closed，内部0-based half-open。编号跨文件精确关联，不按顺序。组装比较是规模和结构统计，不能替代序列比对；多重功能归属不能求和为独立基因总数，核心种质不与登记样品重复相加。

## 界面与同步优化

地图左右栏通过边缘箭头收起及展开，缩略图保留，中央不设置面板按钮组；空间检索按侧栏状态及可用屏幕空间布局。顶部菜单适应宽度，必要时内部横向滚动。专题和分析标签强化按钮选中态，分组依据与统计指标有独立标签及选项。环图底注位于独立留白区，随SVG导出。在线帮助、离线PDF及页面介绍同步更新。
