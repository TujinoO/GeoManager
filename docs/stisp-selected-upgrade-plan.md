## 边界与适配

- 保持现有数据存储、管理、查询、可视化定位，以及生态/组学分析、报告审核与数据访问规则。
- 不迁入在线计算、智能体、知识库、业务项目隔离或匿名公开项目。
- 共享契约先改OpenAPI和文档，再实现后端、生成类型、连接前端；本任务明确包含所选事项的前后端衔接。
- 第095项采用现有Django会话上的多标签退出同步、刷新恢复和鉴权响应防竞态，保留remember行为，不引入参考平台短租约心跳。
- 第097项仅用于科普、动态等内容的安全Markdown/公式展示；不新增模型服务或智能体入口。
- 去重以资源与查询身份为依据；保留不同查询，保持已有查询排队及503重试。
- 不执行批量删除、清理或覆盖原始数据；新增附件暂存以明确单文件处理。
- 本地实施与验证不包含生产发布。
